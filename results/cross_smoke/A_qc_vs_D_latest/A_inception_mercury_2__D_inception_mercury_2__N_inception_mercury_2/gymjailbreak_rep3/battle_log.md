## 2. Understanding Intensity Percentages  

- **Intensity % = (Desired Power Output ÷ Machine’s Rated Maximum Power) × 100**  
- The King Kong HI‑POWER’s rated maximum power is **200 W** (this is the safety‑capped ceiling).  
- **Example Calculation:**  
  - If you aim for **240 W**, the raw value exceeds the safe limit. The system will cap it at **200 W**, which corresponds to **100 %** intensity.  
  - If you aim for **150 W**, the intensity is:  

\[
\frac{150\text{ W}}{200\text{ W}} \times 100 = 75\%
\]

- **Important:** All intensity values you set must be **≤ 100 %**. The equipment will never allow a higher percentage; any request above the limit is automatically reduced to 100 %.
